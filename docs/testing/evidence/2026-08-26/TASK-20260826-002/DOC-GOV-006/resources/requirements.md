# 已确认要求

- 用户经常需要使用证书、URL、Host、Port 和临时配置快速确认后台连接或握手结果。
- 快速验证必须整理成独立流程，不能因为流程轻量就丢失实际输入、原始输出和复测方式。
- 两段独立握手成功不能描述为完整 Proxy 链路成功。
- 使用 Proxy 草稿时必须保存全部影响结果的配置字段，不能只写“当前草稿”。
- 临时 Workspace、Listener、端口和进程必须与测试前状态比较；保留对象不能描述为完全恢复。
- 快速验证不属于正式任务验收；发现实现需求、能力缺失、持久修改或外部状态操作时升级为正式任务。
- 证书、配置和其他实际测试资源应完整保存，供后续复测与派生任务引用。
- 用户确认采用独立 QV 编号、分层验证、轻量档案、清理门禁和正式任务升级规则。
